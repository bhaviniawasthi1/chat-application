SyncTalk

a portfolio project · real-time chat · exactly two seats

Two seats. One conversation.
No third wheels allowed.

This isn't a real messaging app with millions of users — it's a demo built to show off real-time chat, done properly. There are only two accounts, ever. Grab one below, then send this page's link to a friend and have them grab the other. Whoever's holding a seat when you show up will just have to wait.

How it works: pick an account, log in, and start chatting. The moment you log out, your seat opens back up for the next pair of visitors. It's first-come, first-served — so if both accounts show "in use," someone's already mid-conversation. Circle back in a bit.
